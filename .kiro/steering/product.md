# InteractiveInvestor — Product Overview

InteractiveInvestor is a personal web application for viewing and managing stock portfolios held in an [Interactive Investor](https://www.ii.co.uk/) brokerage account.

## Core Purpose
- Display portfolio holdings, performance, and transaction history sourced from an Interactive Investor account
- Provide a dashboard interface for analysing investment data

## Current State
The project is in early development. The Django web app has a single `dashboard` app with a stub index view. Data exploration is being done in Jupyter notebooks before being wired into the web layer.

## Target Users
Personal use — the account holder managing their own Interactive Investor portfolio.
